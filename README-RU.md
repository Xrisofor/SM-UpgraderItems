# Upgrader Items / RU

![Mod Preview](https://github.com/Xrisofor/SM-UpgraderItems/blob/main/preview.jpg?raw=true)

**Upgrader Items** меняет один предмет на другой - если повезет. Мод сам считает шансы, по реальной ценности вещей.

# Как это работает

В боте два слота: в один кладёте предмет, который отдаёте, в другой - предмет, который хотите получить взамен. Мод сравнит их ценность и посчитает шанс. Жмёте кнопку - по колесу побежит стрелка: если она остановится в оранжевой зоне, отданный предмет превратится в желаемый. Если нет - предмет будет потерян.
 
Ценность не прописана вручную. Каждый предмет оценивается по его настоящим рецептам крафта (Craftbot, Portable Craftbot, Mechanic Station, Refinery, Farmer Hideout и другие) - мод разворачивает цепочку рецептов до сырья и складывает стоимость ингредиентов. Для сырья и предметов без рецепта (руда, металлический лом, компонент кити и другие) ценность считается по их физическим характеристикам - объёму, материалу и игровым рейтингам прочности, плавучести, трения и плотности.
 
Шанс успеха = 0.9 × (ценность вашего предмета ÷ ценность цели), но не меньше 0.1% и не больше 90%.

# Особенности модификации

- **Ценообразование по реальным рецептам** - если у предмета есть рецепт крафта, его цена вычисляется рекурсивно из ингредиентов, вплоть до сырья.
- **Честный расчёт для сырья** - предметы без рецепта оцениваются по объёму, материалу и рейтингам.
- **Гибкая ставка** - множители x2/x4/x8 поднимают цену цели и, соответственно, понижают шанс.
- **Серверная авторизация результата** - расчёт шанса и исход спина проверяются на сервере; клиент только анимирует колесо и бота.
